---
name: MMT Global free B2B network
description: The fixed mission for MMT Global's social-benefit B2B network and the boundaries that prevent strategy drift.
---

MMT Global's primary project is a free, social-benefit B2B network. Producer promotions/listings, buyer announcements/requests, and core matchmaking and service access must remain free. The near-term objective is trust, reach, and useful connections—not profit, payment collection, or physical retail.

**Why:** The user explicitly chose this direction after weighing financial and brand goals. Charging producers or buyers, or repeatedly pivoting toward POS, paid marketplace features, or stores, would conflict with the mission and create confusion.

**How to apply:** Keep website and social copy free-first; prioritize verified profiles, safe matching, multilingual communication, and practical support. If a feature involves fees, flag it as outside the agreed line before building. Future sponsorships, grants, or voluntary operating support must not turn core access into a paid service. Warn the user when a proposed step drifts toward paid access, payment-first operations, inventory-heavy retail, or a different product direction. Supporting the user means protecting this mission while clearly calling out legal, financial, safety, and operational risks.
