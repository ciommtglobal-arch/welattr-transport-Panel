---
name: MMT Global language rollout
description: Six-language release scope and boundaries for user-submitted business content.
---

The user requires TR / EN / AR / KU / RU / UA in the pre-publication system check. This scope includes operational screens and sign-in, not only the public language selector. Turkish remains the default, and Arabic must use RTL. User-submitted listing and request text stays in its original language unless an explicit translation feature is designed.

**Why:** The user explicitly requested all six languages as part of the full system check. Automatically translating user content could change commercial meaning or create misleading claims.

**How to apply:** Translate interface copy, navigation, forms, filters, status messages, and legal/business content through the shared i18n layer. Do not claim complete language coverage just because a selector works. Treat user content, official contact details, and regulated/payment wording as separately reviewed content.
