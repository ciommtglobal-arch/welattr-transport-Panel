---
name: MMT Global language rollout
description: Language coverage and translation boundaries for the public MMT Global website.
---

The public website uses Turkish as the default language and supports English, Arabic, and Russian UI translations. Arabic must set the document direction to RTL. User-submitted listing and request text stays in its original language unless an explicit translation feature is designed.

**Why:** MMT Global is intended for international business connections, but automatically translating user content could change commercial meaning or create misleading claims.

**How to apply:** Translate interface copy, navigation, forms, filters, status messages, and legal/business content through the shared i18n layer. Treat user content, official contact details, and regulated/payment wording as separately reviewed content.
