# MMT GLOBAL — CENTRAL INTEGRATION IMPLEMENTATION

Mevcut MMT Connect projesini baştan yazmadan incele ve kurumsal seviyede merkezi entegrasyon altyapısını uygula.

## 1. Önce mevcut projeyi incele

* Projenin framework'ünü, klasör yapısını, giriş dosyalarını, mevcut API rotalarını, veritabanını ve kimlik doğrulamasını tespit et.
* package.json, mevcut ortam değişkenleri ve kullanılan kütüphaneleri incele.
* Mevcut çalışan özellikleri, kullanıcıları ve verileri koru.
* Mevcut mimariyle uyumsuz ikinci bir sunucu veya gereksiz bir veritabanı oluşturma.

## 2. Merkezi entegrasyon dosyası

Proje TypeScript kullanıyorsa uygun konumda `mmtIntegrationWiring.ts` dosyasını oluştur.

Bu dosyada şu modülleri merkezi olarak düzenle:

* Entegrasyon yapılandırması ve durum kontrolü
* Güvenli API istemcisi ve hata yönetimi
* Telegram Bot API bağlantısı ve webhook işleme
* WhatsApp Business Cloud API bağlantısı ve webhook doğrulaması
* MMT Global kurumsal web sitesi bağlantı noktaları
* CRM ve operasyon olayları için bildirim arayüzü
* Sağlık kontrolü ve bağlantı durumları
* Tekrarlanan webhook olaylarını önleme ve yapılandırılabilir zaman aşımı

## 3. Yönetim paneli

Mevcut arayüzün tasarım dilini koruyarak entegrasyon durumlarını yönetim panelinde göster:

* Telegram: yapılandırılmadı / bağlı / hata
* WhatsApp: yapılandırılmadı / bağlı / hata
* Kurumsal site API bağlantısı
* Son bağlantı kontrolü ve hata kayıtları
* Yetkili kullanıcılar için güvenli bağlantı ayarları

Bağlantı durumu yalnızca gerçek API kontrolü başarılıysa bağlı gösterilsin. Yapılandırılmamış servisler sahte şekilde aktif gösterilmesin.

## 4. Güvenlik

* API anahtarlarını ve token'ları kaynak koda yazma.
* Replit Secrets veya mevcut güvenli ortam değişkenlerini kullan.
* Telegram ve WhatsApp webhook'larında ilgili platformların doğrulama yöntemlerini uygula.
* WhatsApp webhook imza doğrulamasını atlama.
* Token'ları, şifreleri veya kişisel verileri loglama.
* Mevcut giriş sistemini ve rol tabanlı yetkilendirmeyi koru.
* İzin kontrolü olmadan yönetim veya finans verilerini açığa çıkarma.
* Webhook tekrarlarına ve kötü amaçlı isteklere karşı koruma uygula.

## 5. Ortam değişkenleri

Gerekli değişkenleri mevcut mimariye göre tanımla ve eksik olanları belgele:

* TELEGRAM_BOT_TOKEN
* TELEGRAM_WEBHOOK_SECRET
* WHATSAPP_ACCESS_TOKEN
* WHATSAPP_PHONE_NUMBER_ID
* WHATSAPP_VERIFY_TOKEN
* WHATSAPP_APP_SECRET
* PUBLIC_APP_URL

Değerleri örnek veya boş bırak; gerçek sırları üretme ya da tahmin etme.

## 6. Projeye entegrasyon

* Yeni dosyayı mevcut sunucuya ve API rotalarına bağla.
* Mevcut paket yöneticisini ve kod standartlarını kullan.
* Çakışan fonksiyonları veya yinelenen servisleri tespit et.
* Gerekli bağımlılıkları yalnızca ihtiyaç varsa ekle.
* Örnek mesajları gerçek müşterilere otomatik gönderme.
* Gerçek mesaj gönderimini açıkça yetkilendirilmiş API çağrısı ve yapılandırma gerektiren bir işlem olarak tut.

## 7. Test ve teslim

* TypeScript tür kontrolünü ve mevcut testleri çalıştır.
* Mümkünse üretim derlemesini çalıştır.
* Başarısız kontrolleri ve düzeltmeleri raporla.
* Eksik Secrets veya API izinlerini açıkça belirt.
* Sonuçta değiştirilen dosyaları, yeni API uç noktalarını, gereken ortam değişkenlerini ve test sonuçlarını listele.

Önce mevcut kod tabanını analiz et. Ardından uyumlu değişiklikleri uygula; tüm projeyi gereksiz yere yeniden oluşturma. Tamamlanmayan entegrasyonları çalışıyor gibi gösterme.
